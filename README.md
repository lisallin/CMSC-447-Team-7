***WINDOWS USERS ONLY***

We are using Python 3.11.8 for this project. To ensure everything works as intended please go to https://www.python.org/downloads/windows/ for windows,
and scroll to the 3.11.8 download. Download it and then run the following command after the download is complete.

Before running the line below, to ensure you have Python 3.11 successfully installed, run:
py -0

If you see a list of Python versions, check for something like "-V:3.11          Python 3.11 (64-bit)", then you're good!

To run ALL dependencies on Python version 3.11:
py -3.11 -m pip install -r requirements.txt

To run the code on Windows using Python 3.11:
py -3.11 manage.py runserver
